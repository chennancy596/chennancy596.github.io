## Design

The look borrows the quiet night-sky mood of the game **_To the Moon_**:

- a twinkling starfield behind every page and hand-coded moonlit landscapes (moon, hills, lighthouse, paper rabbits), drawn with Canvas
- translucent dialogue boxes with name tags, and thin "memento" frames around photos
- gentle rain in Chapter Four of the story, and background music that alternates between two soundtrack pieces
- one shared grid: centred page titles over a two-column timeline, with a consistent spacing scale

Type is set in **Spectral** (serif) and **Instrument Sans**, with **Noto Serif SC** for Chinese. It works on phones and desktops and respects "reduce motion" settings.

## Built with

Plain HTML, CSS and JavaScript in a single `index.html`. There is no framework and no build step. GitHub Pages serves it straight from the `main` branch.

```
index.html                         the whole site (all six pages)
5.jpg 6.jpg 17.jpg 18.jpg 20.jpg   photos
everythings-alright.mp3            background music, track 1
for-river.mp3                      background music, track 2
```

**To update the site:** upload a new `index.html` (same name) and commit to `main`. The live site refreshes within a few minutes; press Cmd/Ctrl + Shift + R to skip the browser cache.
