## Design

The look borrows the quiet night-sky mood of the game **_To the Moon_**:

- a twinkling starfield behind every page
- hand-coded moonlit landscapes (moon, hills, lighthouse, paper rabbits), drawn with Canvas and no image files
- translucent dialogue boxes with name tags, and thin "memento" frames around photos
- gentle rain in Chapter Four of the story
- background music that alternates between two soundtrack pieces

Type is set in **Spectral** (serif) and **PT Sans**, with **Noto Serif SC** for Chinese. It works on phones as well as desktops, and respects "reduce motion" settings.

## Built with

Plain HTML, CSS and JavaScript in a single `index.html`. There is no framework and no build step. GitHub Pages serves it straight from the `main` branch.

```
index.html                 the whole site (all six pages)
5.jpg 6.jpg 17.jpg 18.jpg 20.jpg   photos
everythings-alright.mp3    background music, track 1
for-river.mp3              background music, track 2
```

**To update the site:** edit `index.html` (or upload a new copy with the same name) and commit. The live site refreshes within a few minutes.
